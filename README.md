# BFSI_Dashboard_PROJECT
This project focuses on analyzing Banking, Financial Services and Insurance (BFSI) transaction data using Microsoft Excel. It demonstrates data cleaning, data analysis, Excel formulas, Pivot Tables and dashboard reporting.

## Project Objectives
- Analyze banking transaction data.
- Understand customer transaction patterns.
- Analyze transaction amounts by city.
- Examine different account and transaction types.
- Monitor transaction status and banking channels.
- Present key information through an Excel dashboard.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas
- Data Cleaning
- Pivot Tables
- Data Analysis

## Dataset Details
The practice dataset contains approximately 500 transaction records, including:
- Transaction ID
- Transaction Date
- Customer Name
- City
- Account Type
- Transaction Type
- Channel
- Amount
- Balance
- Transaction Status

## Project Workflow
1. Imported and explored the banking dataset.
2. Practiced data cleaning and formatting.
3. Applied Excel formulas.
4. Created Pivot Tables for analysis.
5. Analyzed transaction amounts and banking channels.
6. Prepared an Excel dashboard.
